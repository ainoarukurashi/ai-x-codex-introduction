# AI-X Codex導入

AI-X講座の受講者向けに、Codexデスクトップアプリの事前準備を案内する静的ページです。

## 内容

- `index.html`: 公開用の案内ページ
- `initial-settings.html`: 余裕がある方向けのCodex初期設定ガイド
- `windows-troubleshooting.html`: Windows版の詳細トラブルシューティング
- `styles.css`: ページのスタイル
- `assets/`: Mac版・Windows版のスクリーンショット画像、Windowsエラー再現画像
- `Codexデスクトップ_事前準備ガイド.md`: 事前準備の文章版
- `Codexデスクトップ_セットアップガイド_Mac版.md`: Mac版セットアップガイド
- `Codexデスクトップ_セットアップガイド_Windows版.md`: Windows版セットアップガイド

## 公開

Vercelで静的サイトとして公開します。
