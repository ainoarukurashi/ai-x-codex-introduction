# AI-X導入

AI-X講座の受講者向けに、CodexとClaude Codeのアプリ準備を案内する静的ページです。

## 内容

- `index.html`: 最低限Codex、できればClaude Codeも準備するトップページ
- `codex.html`: Codexインストールガイド
- `claude.html`: Claude Codeインストールガイド
- `claude-desktop.html`: 旧URLからClaude Codeインストールガイドへ移動するリダイレクトページ
- `initial-settings.html`: 事前準備後に確認するCodex初期設定ガイド
- `claude-code-initial-settings.html`: 事前準備後に確認するClaude Code初期設定ガイド
- `windows-troubleshooting.html`: Windows版の詳細トラブルシューティング
- `styles.css`: ページのスタイル
- `assets/`: Mac版・Windows版のスクリーンショット画像、Claude Codeインストールガイド用スクリーンショット画像、Codex初期設定画像、Windowsエラー再現画像
- `Codexデスクトップ_事前準備ガイド.md`: 事前準備の文章版
- `Codexデスクトップ_セットアップガイド_Mac版.md`: Mac版セットアップガイド
- `Codexデスクトップ_セットアップガイド_Windows版.md`: Windows版セットアップガイド

## 公開

Vercelで静的サイトとして公開します。
